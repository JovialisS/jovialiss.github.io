## **vim常用命令**


### **复制、删除、粘贴**

| 复制 | `yy` `nyy` | 复制当前行/n行 |
|---|---|---|
| 删除 | `dd` `ndd` `d$` | 删除当前行/n行/到行尾 |
| 粘贴 | `p` `P` `gp` | 粘贴到光标后/前 |
| 撤销 | `u` | 撤销上一步 |
| 重做 | `Ctrl+r` | 恢复被撤销的内容 |

### **可视模式**

| 字符/行/块选择 | `v` `V` `Ctrl+v` | 字符/整行/矩形块 |
|---|---|---|
| 复制选中内容 | `y` | 选中后按 `y` 复制 |
| 删除选中内容 | `d` | 选中后按 `d` 删除 |

### **光标移动**

| 左/下/上/右 | `h` `j` `k` `l` | 基础方向移动 |
|---|---|---|
| 行首/行尾 | `0` `$` | 跳到行首/行尾 |
| 文件首/尾行 | `gg` `G` | 跳到第一行/最后一行 |
| 指定行号 | `nG` | 如 `10G` 跳到第10行 |
| 按单词跳转 | `w` `b` | 下一/上一单词开头 |

### **模式切换**

| 插入模式 | `i` `a` `o` `I` `A` | 光标前/后/下方/行首/行尾插入 |
|---|---|---|
| 可视模式 | `v` `V` `Ctrl+v` | 字符/整行/矩形块选择 |
| 底行模式 | `:` | 执行保存、搜索等命令 |
| 返回普通模式 | `Esc` | 任意模式返回 |

### **底行命令**

| 强制退出 | `:q!` | 不保存直接退出 |
|---|---|---|
| 保存并退出 | `:wq` | 最常用 |
| 显示行号 | `:set nu` | 关闭用 `:set nonu` |
| 搜索 | `/关键词` | `n` 找下一个，`N` 找上一个 |
| 取消高亮 | `:noh` | 清除搜索高亮 |
| 当前行替换 | `:s/old/new/` | 替换第一个匹配 |
| 当前行全部替换 | `:s/old/new/g` | 当前行全局替换 |
| 全文替换 | `:%s/old/new/g` | 整个文件全局替换 |
| 全文替换确认 | `:%s/old/new/gc` | 每处替换前询问 |

## **Chromium 弹窗 '缺少 Google API 密钥...'**

### **创建配置文件**

> sudo mkdir -p ~/.config/chromium

> sudo vim ~/.config/chromium/ignore-api-warning.conf

```
export GOOGLE_API_KEY="none"
​export GOOGLE_DEFAULT_CLIENT_ID="none"
​export GOOGLE_DEFAULT_CLIENT_SECRET="none"
```

### **修改桌面启动文件**

> sudo vim /usr/share/applications/chromium.desktop

```
[Desktop Entry]
​Name=Chromium
​Name[zh_CN]=Chromium浏览器
​Comment=Open source release of chrome.
​Comment[zh_CN]=Chrome浏览器开源版本。
​#Exec=/opt/apps/org.chromium.www/files/chromium/chrome --no-sandbox %U
​Exec=bash -c "source /home/pdsyw/.config/chromium/ignore-api-warning.conf && /opt/apps/org.chromium.www/files/chromium/chrome  %U"
Terminal=false
​Type=Application
```
